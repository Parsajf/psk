# نسخهٔ مستقل وب‌سایت پاک سرا کارن

این پوشه یک کپی مستقل از قالب اصلی سایت است. صفحه‌ها با HTML، استایل‌ها با CSS و رفتارهای تعاملی با JavaScript ساده ساخته شده‌اند و به ابزار ساخت یا وابستگی سمت سرور نیاز ندارند.

## ساختار

- `index.html` — صفحهٔ اصلی
- `projects.html` — فهرست پروژه‌ها
- `project-single.html` — صفحهٔ پروژه
- `blog.html` — فهرست مقاله‌ها
- `blog-single.html` — صفحهٔ مقاله
- `about.html` — دربارهٔ ما
- `assets/css/main.css` — استایل‌های سایت
- `assets/js/main.js` — رفتارهای تعاملی
- `assets/fonts/` و `assets/images/` — فونت‌ها و تصاویر

برای مشاهدهٔ محلی، از داخل همین پوشه دستور `python3 -m http.server 8001` را اجرا کنید و نشانی `http://localhost:8001/index.html` را باز کنید.
